# Frontend

## 로그인과 내 코스

`/login`에서 이메일·비밀번호로 가입하거나 로그인합니다. 가입 후 바로 로그인됩니다.
비밀번호는 10자 이상, UTF-8 기준 72바이트 이하입니다. 이메일 인증·비밀번호 재설정은 후속 기능입니다.
세션 쿠키는 HttpOnly·SameSite=Lax이며 프로덕션에서는 Secure를 사용하므로 HTTPS가 필요합니다.
로컬에서는 `npm run dev`를 사용하세요. 세션 원문은 JS/localStorage에 보관하지 않습니다.
브라우저는 Next.js API에 같은 출처로 요청하고 Next.js가 Kotlin에 세션 토큰을 전달합니다.

`/my/courses`는 내 코스 최신 100개, `/courses/new`는 작성 화면,
`/courses/{id}/edit`는 작성자 전용 수정 화면입니다.
상세 화면에서 공개/비공개 전환·공유 URL 복사·삭제 확인을 지원합니다.
비공개 코스는 작성자만 열 수 있고 다른 사용자에게는 404로 처리합니다.

## 사용자 코스 작성 화면

`/courses/new`에서 Leaflet + OpenStreetMap 지도에 경로점을 직접 입력합니다.
기존 `/admin/courses/new` 주소는 새 작성 화면으로 이동합니다.
지도 클릭으로 추가하고 번호점을 드래그해 수정합니다. 점 선택 후 삭제, 되돌리기,
전체 지우기, 출발점 연결을 지원합니다. 닫힌 경로에 점을 추가하려면 먼저 되돌리세요.
왕복형은 돌아오는 경로까지 직접 입력해야 합니다.
`현재 위치로 이동` 버튼을 누를 때만 위치 권한을 요청합니다. 확인한 위치로 지도를 이동하고
파란 점으로 표시하며, 작성 중인 경로는 유지합니다. 현재 위치를 코스에 자동 추가하지 않습니다.
HTTPS 또는 localhost가 필요하며 권한 거부·시간 초과·위치 확인 실패는 화면에 안내합니다.

이름과 경로를 작성한 뒤 `비공개로 저장` 토글로 공개 범위를 선택하고 `코스 저장`을 누르면 로그인 사용자 소유의 코스로 저장합니다. 기본값은 비공개(토글 켜짐)이며 끄면 공개입니다. 수정 화면에도 동일한 토글이 표시되며 `수정 저장`을 눌러야 반영됩니다.
경로는 `[경도, 위도]` 순서의 LineString이며 예상 거리는 선분 길이의 합입니다.
실제 보행로 연결이나 보행 가능 여부를 자동 검증하지 않습니다.
최종 거리는 PostGIS가 계산합니다. 성공 후 상세 링크로 이동할 수 있습니다.
API 규칙은 [코스 저장 API](../docs/api/course-create.md)를 참고하세요.
기존 관리자 키 방식은 제거했습니다. 저장 전 페이지를 떠나면 초안이 사라집니다.
작성·수정·상세 지도를 모두 Leaflet + OpenStreetMap으로 제공합니다.

OSM 출처 표시는 지도에 유지합니다. 기본 공개 타일 서버는 일반적인 대화형 열람에만
사용하며 대량 수집·오프라인 다운로드를 하지 않습니다. 운영 규모가 커지면
별도의 타일 제공자로 전환하세요. `NEXT_PUBLIC_OSM_TILE_URL`로 URL을 설정할 수 있으며,
제공자를 바꾸면 요구되는 출처 표시도 함께 변경해야 합니다.

설정과 실행 방법은 [루트 README](../README.md)를 참고하세요.

## 코스 목록
`/`에서 Server Component가 `BACKEND_URL/api/courses`를 호출합니다.
Kotlin 서버와 DB를 실행하면 공개 코스 목록을 확인할 수 있습니다.

- URL 예: `/?page=0&size=3` (page는 0부터, size는 3·6·12 중 선택, 기본값 6)
- 페이지당 개수 적용 시 첫 페이지로 이동합니다.
- 잘못된 페이지·검색 조건은 기본 목록 `/`로 이동합니다.
- 로딩: Suspense 스켈레톤, 실패: error boundary와 재시도, 빈 목록: 안내 화면.
- `현재 위치 사용` 버튼을 누르면 브라우저 위치 권한을 요청하며, 위치 확인만으로는 검색하지 않고 `코스 찾기`를 눌러야 적용됩니다.
- 검색 반경은 1·2·5·10km, 목표 코스 거리는 3·5·10·15km 중 선택합니다. 목표 거리의 ±10%가 조회됩니다.
- 위치 검색 결과는 가까운 출발점 순으로 정렬하고 카드에 출발점까지의 직선거리를 표시합니다.
- 검색 조건은 URL에 저장되어 페이지 이동과 상세 화면에서 목록으로 돌아올 때 유지됩니다.
- 코스 거리는 m를 km로 변환해 소수 둘째 자리까지 표시합니다.
- 개발용 샘플에는 가상 경로 안내가 표시됩니다.

## 코스 상세
- 경로: `/courses/{id}`. Server Component가 상세 API를 조회합니다.
- 지도: Leaflet과 OpenStreetMap 타일을 사용합니다. 지도 API 키가 필요하지 않습니다.
- 전체 경로·출발/도착 마커·확대/축소·전체 경로 맞추기를 제공합니다.
- GeoJSON의 [경도, 위도]를 Leaflet의 [위도, 경도]로 변환합니다.
- 지도는 Client Component에서 동적으로 로드하고 종료 시 리스너·지도를 정리합니다.
- 페이지·위치·반경·목표 거리 조건을 전달해 목록 복귀 시 유지합니다.
- 없는 코스·비공개 코스·잘못된 ID는 찾을 수 없음 안내, 통신 실패는 재시도 화면입니다.
- 타일 로드 실패·15초 시간 초과 시 경로는 유지하고 배경 지도 재시도를 제공합니다.
- 등록 코스는 출발점과 도착점이 일치한다는 V1 규칙을 사용합니다.

## 지도 설정
추가 설정 없이 기본 OSM 공개 타일을 사용합니다.
선택적으로 `NEXT_PUBLIC_OSM_TILE_URL`에 `{z}/{x}/{y}` 템플릿 URL을 지정할 수 있습니다.
타일 제공자를 변경한다면 `src/lib/leaflet-map.ts`의 출처 표시와 최대 줌도 해당 정책에 맞게 변경하세요.
환경변수 변경 후에는 개발 서버를 재시작하고 프로덕션은 다시 빌드하세요.

- [OSM 공개 타일 정책](https://operations.osmfoundation.org/policies/tiles/)
- [OSM 출처·라이선스](https://www.openstreetmap.org/copyright)
