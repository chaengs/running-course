# 개발용 샘플 코스

## 목적과 한계
코스 목록·상세·지도 경로 표시와 위치/거리 필터 구현을 위한 가상 데이터입니다.
여의도·상암 인근 좌표를 사용하지만 실제 러닝 코스, 보행 가능한 도로, 안전성을 검증한 경로가 아닙니다.
코스 이름과 설명에 개발용임을 표시했습니다. 실제 서비스 DB에서는 실행하지 마세요.

## 데이터 구성
| 이름 | 목표 길이 | 유형 | 공개 | 확인할 동작 |
|---|---|---|---|---|
| [개발용] 여의도 3km 순환 | 약 3km | LOOP | 예 | 짧은 코스·거리 필터 |
| [개발용] 여의도 5km 순환 | 약 4.8km | LOOP | 예 | 5km ±10% 조건 포함 |
| [개발용] 여의도 5km 왕복 | 약 5.2km | OUT_AND_BACK | 예 | 5km ±10% 조건 포함·왕복 유형 |
| [개발용] 상암 10km 순환 | 약 10km | LOOP | 예 | 다른 지역 탐색·반경 밖 제외 |
| [개발용] 여의도 비공개 5km | 약 5km | LOOP | 아니오 | 공개 검색에서 제외 |

출발점과 도착점은 일치합니다. 경로는 GeoJSON LineString geometry이며 좌표 순서는 경도, 위도입니다.
`distance_meters`는 표시용 이름에서 가져오지 않고 PostGIS가 경로의 geography 길이를 계산해 반올림합니다.
고도, 신호등, 노면, 실제 도로 주행거리는 반영하지 않습니다.

## 실행
먼저 DB를 켜고 백엔드를 한 번 실행해 Flyway 초기 마이그레이션을 완료하세요.
그다음 저장소 루트에서 다음 명령을 실행합니다.

```sh
docker compose exec -T db sh -c 'psql -v ON_ERROR_STOP=1 -U "$POSTGRES_USER" -d "$POSTGRES_DB"' < scripts/db/seed-courses.sql
```

현재 macOS 환경에서 `docker compose`가 인식되지 않으면 전체 경로를 사용합니다.

```sh
/Applications/Docker.app/Contents/Resources/cli-plugins/docker-compose exec -T db sh -c 'psql -v ON_ERROR_STOP=1 -U "$POSTGRES_USER" -d "$POSTGRES_DB"' < scripts/db/seed-courses.sql
```

반복 실행 시 같은 이름의 코스는 추가하지 않습니다. 기존 코스는 덮어쓰지 않습니다.
같은 샘플 이름이 중복되거나 기존 샘플이 변경되었다면 검증에서 실패하고 트랜잭션을 취소합니다.
기존 샘플 수정이 필요하면 해당 데이터의 변경 의도를 먼저 확인하세요.
자동 실행하는 Flyway SQL에 넣지 않았으므로 앱 시작이나 운영 배포 시 자동으로 들어가지 않습니다.

## 검색 구현 시 기대 결과
- 기준점: 여의도 경도 126.9340, 위도 37.5280, 반경 2,000m
- 공개 코스만 조회하면 여의도 3개가 검색됩니다.
- 목표 5km의 ±10%(4,500~5,500m) 조건을 더하면 여의도 2개가 검색됩니다.
- 상암의 경도 126.8850, 위도 37.5680, 반경 2,000m, 목표 10km ±10%이면 상암 1개가 검색됩니다.
- 비공개 샘플은 어떤 공개 검색에서도 반환하면 안 됩니다.
- 출발점까지 거리는 경로 길이와 별개이며, geography를 이용한 직선거리입니다.
