# 작성 중 코스의 고도 미리보기

`POST /api/my/elevation` (인증 필요), 본문은 `{ "routeGeojson": { "type": "LineString", "coordinates": [[경도, 위도], ...] } }`입니다.
브라우저는 동일 출처의 Next.js `/api/elevation`을 사용하며 Origin과 HttpOnly 세션 쿠키를 검증합니다.

- 미완성 경로도 계산 가능합니다. 최소 2점, 최대 10000점, 길이 1m~100km, 유효한 WGS84 좌표를 검증합니다.
- 약 50m 간격으로 구면 보간합니다. 요청 부담을 제한하기 위해 최대 500개 지점이며, 약 25km 이상 경로는 간격이 넓어집니다. 거리 기준은 고도 미리보기용 구면 거리이며 최종 저장 거리는 기존 PostGIS가 결정합니다.
- `srtm30m`을 bilinear 방식으로 조회합니다. 동일 좌표(닫힌 경로의 출발·도착 포함)를 재사용하며 요청당 최대 100지점으로 분할합니다.
- 중앙값 3개 평활화, 5m 방향 전환 임계값을 초기 실험 기준으로 사용합니다. 연속된 1m 상승도 누적하며 작은 반대 방향 흔들림은 무시합니다. 열린 경로의 양 끝은 원본 유지, 닫힌 경로는 순환 중앙값으로 시작·끝 일치 처리합니다.
- 응답: `samples`(거리·처리 고도·원본 고도), 최저·최고 고도, 예상 상승·하강, 거리, 실제 조회 간격, `dataset`, `calculatedAt`, `algorithmVersion`, `difficulty`(고도 기반 난이도·m/km·정책 버전).
- 데이터가 없으면 422로 처리하며 0m로 대체하거나 누락 구간을 연결하지 않습니다. 서비스 장애는 503, 호출 제한은 429입니다.
- 단일 Kotlin 프로세스에서 전체 조회를 직렬화하고 요청 시작 간격을 1.1초로 제한합니다. 동시 조회는 429, 일별 호출은 UTC 기준 900회까지입니다. 재시작 시 카운터가 초기화되므로 운영에서 여러 인스턴스로 확장하거나 재시작이 잦아지면 공유 호출 제한 저장소가 필요합니다.
- 외부 호출은 DB 트랜잭션 밖에서 수행합니다. `elevation.api-url` / `ELEVATION_API_URL`은 운영자만 설정하며 기본값은 `https://api.opentopodata.org/v1/srtm30m`입니다. 테스트에서만 가짜 서버로 바꿉니다.

Stitch Course Making 화면의 지도 아래 4개 지표 카드·파란 면적 그래프를 참고했습니다. 목업 고도 수치·예상 페이스·GPS 보정 표시는 사용하지 않습니다.
작성·수정 화면에서 서로 다른 경로점 3개 이상을 찍고 출발·도착점을 연결하면 1.2초 후 고도를 자동 조회합니다. 닫힌 경로를 수정한 경우에도 변경이 멈춘 뒤 다시 계산합니다. 수정 페이지의 기존 닫힌 경로도 자동 계산합니다. 이름·설명·공개 범위·선택한 점만 바꾸는 경우 재조회하지 않습니다.
그래프 위 포인터 이동 또는 그래프 선택 후 좌우 방향키(Home/End 포함)로 지점별 고도를 확인합니다. 별도 경로 위치 슬라이더는 표시하지 않습니다. 경로 변경 시 이전 결과는 즉시 숨기고 진행 중 응답·재시도·대기 타이머는 취소·무시합니다. 진행 중이던 Kotlin 외부 조회가 끝나지 않아 429가 오면 1.5·3·6초 뒤 최대 3회 재시도합니다(전체 45초 제한). 오류가 남으면 '다시 시도' 버튼을 표시합니다. 무한 재시도는 하지 않으며 코스 저장은 계속 가능합니다. 프론트엔드 요청 취소가 이미 시작된 서버의 외부 호출을 취소한다고 보장하지 않습니다.
그래프 세로축은 최소 100m 범위를 유지하고 실제 고도 눈금을 표시합니다. 변화가 큰 경로는 25·50·100m 등 읽기 쉬운 간격으로 범위를 확장합니다. 1~2m 변화가 화면 전체에 과장되지 않도록 하는 시각화 변경이며, 약 50m 샘플링과 누적 고도·난이도 계산은 유지합니다. 표시한 높이 차이는 최고-최저로, 누적 상승과는 다릅니다.
요약 카드는 전체 거리·누적 고도(누적 상승)·최고 고도·예상 난이도로 표시합니다. [고도 기반 예상 난이도 v1](../elevation-difficulty.md)에 자료 조사와 자체 기준을 정리했습니다.
현재 범위는 미리보기이며 DB 저장과 상세 화면 고도 표시는 포함하지 않습니다. 고도 API 실패는 코스 저장에 영향을 주지 않습니다. 다리·터널 높이 보정은 v2입니다.
