# 러닝 코스 탐색·작성 서비스 PRD

현재 코드 대조일: 2026-10-27. 배포 주소와 실행 방법은 [README](../README.md)를 참고합니다.

## 해결하려는 문제

러너는 달리기 전에 원하는 거리와 장소에 맞는 길을 정해야 합니다.
익숙한 3km에서 5km로 거리를 늘리거나, 새로운 동네에서 달릴 때 출발점·경유지·복귀 경로를 직접 가늠하기 어렵습니다.
Running Course는 지도에서 실제 도보 경로와 거리를 확인하며 코스를 만들고, 주변의 공개 코스를 발견·저장·공유하도록 돕습니다.

## 주요 사용자

- 거리 늘리기에 도전하는 초보 러너
- 새로운 장소에서 코스를 찾는 러너
- 직접 만든 코스를 보관하거나 다른 사람과 공유하려는 러너

## 현재 제공 흐름

### 공개 코스 탐색

로그인 없이 공개 목록·상세를 봅니다. 현재 위치 또는 주소·장소 검색으로 위치를 설정하고 반경·거리를 선택합니다.
위치 검색은 **코스 출발점까지의 직선거리** 기준이며, 출발점으로 걸어가는 거리나 경로의 일부가 근처를 지나는 조건이 아닙니다.
목표 거리 선택은 3km(4km 이하), 5km(4km 초과~7km 이하), 10km(7km 초과~11km 이하), 그 이상(11km 초과) 구간입니다. API에서 목표 거리와 최소 거리 조건은 함께 사용할 수 없습니다.
목록은 무한 스크롤이며 지도 카드는 별도 경로 미리보기를 사용합니다.

### 코스 작성과 관리

로그인 → 출발점·경유점 선택 → 카카오 도보 경로 연결 → 출발점으로 복귀 → 이름·소개·유형·공개 범위 선택 → 저장합니다.

- Leaflet/OpenStreetMap은 지도 표시·편집, 카카오 API는 구간별 도보 경로 계산을 담당합니다.
- 코스 유형은 순환형(`LOOP`), 왕복형(`OUT_AND_BACK`)입니다. 두 유형 모두 저장 경로는 닫혀 있어야 합니다.
- 지도 지점 추가·이동·삭제·되돌리기와 경로 초기화를 제공합니다.
- 유효한 구간 결과는 재사용하고, 변경으로 요청 입력이 달라진 구간을 재계산합니다.
- 고도 자동 조회와 고도 기준 예상 난이도를 제공하며, 고도 실패가 코스 저장을 막지는 않습니다.
- 새 코스는 비공개 기본값이며 공개로 저장할 수도 있습니다.
- 내 코스에서 상세·수정·삭제·공개 범위 변경·통계를 제공합니다.
- 저장 경로의 거리와 출발점은 서버가 PostGIS로 계산합니다.

### 찜과 공유

로그인한 사용자는 공개 코스를 찜하고 최근 찜 순으로 다시 볼 수 있습니다. 본인의 공개 코스도 찜할 수 있습니다.
공개 상세 주소를 복사해 공유합니다. URL을 안다고 비공개 코스 접근 권한이 생기지는 않습니다.

| 사용자 | 공개 상세·미리보기 | 비공개 상세·미리보기 | 수정·삭제·공개 전환 |
| --- | --- | --- | --- |
| 미로그인 | 가능 | 불가 | 불가 |
| 작성자 | 가능 | 가능 | 본인 코스만 가능 |
| 기존 찜 사용자 | 가능 | 해당 코스에 한해 가능 | 불가 |
| 다른 로그인 사용자 | 가능 | 불가 | 불가 |

비공개 전환 후에도 기존 찜은 유지됩니다. 찜을 해제하면 작성자를 제외한 사용자는 다시 공개되기 전까지 접근할 수 없습니다.

## 구현된 운영·탐색 지원

- Vercel 프론트와 Render 백엔드 배포, DB/PostGIS 상태 확인 API
- 이메일 가입·로그인·로그아웃, DB 세션과 HttpOnly 쿠키
- 찜·내 코스 화면의 토큰 없는 목록 요청 생략, 목록 API의 401에 따른 로그인 이동
- feed의 전체 개수 조회 생략, 미리보기 전용 조회, 상세 요청 중복 제거
- 도보 구간 메모리 캐시·동일 동시 요청 병합·DB 일일 제한: 사용자별 800회, 전체 900회 기본값
- 공개 코스별 검색·공유 메타데이터, 사이트맵과 개인 화면 noindex

이는 구현 범위이며, 성능 개선 수치나 실제 이용 성과를 의미하지 않습니다.

## 현재 제약과 남은 과제

- 목표 거리만으로 코스를 자동 생성·추천하지 않습니다. 사용자가 지점을 선택하면 그 사이를 도보 경로로 연결합니다.
- 고도와 예상 난이도는 지형 데이터 기반 비교 지표이며 개인 체력·노면·안전·실제 운동 강도를 판정하지 않습니다.
- 외부 경로·고도·지역 API와 호스팅의 유휴 후 재시작으로 대기·실패가 발생할 수 있습니다.
- 내 코스 `visibility` 필터는 개수와 페이지 계산에 적용되지만, 현재 목록 SQL에는 빠져 있어 결과 일관성 개선이 필요합니다.
- 소셜 로그인, 이메일 소유 확인, 비밀번호 복구·변경, 인증 요청 속도 제한은 미구현입니다.

## 향후 검토 방향

목표 거리 기반 순환 코스 추천, 노면·경사 조건 검색, GPX 가져오기·내보내기, 완주 기록·리뷰, 신고·검수입니다.
확정 일정이나 이미 제공되는 기능을 뜻하지 않습니다.
