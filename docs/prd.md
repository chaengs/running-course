# 러닝 코스 탐색 웹 PRD

## 문제
러너는 익숙하지 않은 장소에서 목표 거리만큼 달리고 출발점으로 돌아올 경로를 찾기 어렵다.

## 사용자
- 초보 러너: 3km에 익숙해져 집 근처 5km 코스에 도전하고 싶다.
- 열성 러너: 새로운 장소에서 10km 코스를 발견하고 싶다.

## V1
현재 위치 또는 지도에서 선택한 위치 → 주변 코스 검색 → 거리 필터 → 상세 경로 확인 → 저장.
관리자가 검증한 한 지역의 10~20개 코스로 시작한다.
출발점과 도착점이 같은 순환형/왕복형을 구분한다.
목표 거리 ±10%, 출발점까지 직선거리 기준으로 검색한다.
비로그인 탐색, 로그인 후 북마크, 관리자 코스 등록/수정/공개를 제공한다.
검색 결과가 없으면 조건 변경을 안내한다.

## V2 후보
사용자 코스 등록과 검수, 완주 기록/리뷰, 노면/경사 필터, 맞춤 추천, GPX 내보내기.
자동 경로 생성은 별도 기술 검증 후 도입한다.

## 현재 구현 범위
프로젝트 초기 구성, DB 마이그레이션, 상태 확인 API와 프론트엔드 연결 화면.
지도, 코스 API, 로그인과 북마크는 후속 구현이다.
