# 러닝 코스 탐색 웹 PRD

## 문제
러너는 원하는 거리와 장소에 맞는 코스를 직접 만들고, 저장하고, 다른 러너와 공유하기 어렵다.

## 사용자
- 초보 러너: 3km에 익숙해져 집 근처 5km 코스에 도전하고 싶다.
- 열성 러너: 새로운 장소에서 10km 코스를 발견하고 싶다.

## V1
로그인 → 지도에서 코스 그리기 → 거리 확인 → 비공개 저장 → 공개 전환 → URL 공유.
현재 위치 또는 지도에서 선택한 위치 → 공개 코스 검색 → 거리 필터 → 상세 경로 확인 → 북마크.
출발점과 도착점이 같은 순환형/왕복형을 구분한다.
목표 거리 ±10%, 출발점까지 직선거리 기준으로 검색한다.
비로그인 공개 코스 탐색, 로그인 후 내 코스 등록·수정·삭제·공개 및 북마크를 제공한다.
비공개 상세와 수정·삭제·공개 전환은 작성자만 가능하며 서버에서 소유권을 검사한다.
검색 결과가 없으면 조건 변경을 안내한다.

## V2 후보
신고·검수, 완주 기록/리뷰, 노면/경사 필터, 맞춤 추천, GPX 가져오기·내보내기.
자동 경로 생성은 별도 기술 검증 후 도입한다.

## 현재 구현 범위
공개 검색·거리 필터·상세 Google 지도, Leaflet/OSM 코스 편집기, 이메일 가입·로그인·로그아웃,
DB 세션, 사용자 소유 코스 저장·조회·수정·삭제·공개 범위 및 URL 공유를 구현했다.
북마크는 후속 구현이다. 코스 자동 라우팅은 수행하지 않는다.
